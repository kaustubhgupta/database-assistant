# Gen AI Apps

This project is part of the **GenAI Bootcamp**. It provides a collection of applications that help you interact with data using natural language.

## Available Applications

1. **Database Querying** — Ask questions in plain English and generate SQL queries to retrieve information from a database.
2. **Data Chat** — Chat with your data, ask questions, and receive useful insights.

## Usage

Open the application and use the sidebar to select the tool you want to explore.
